## 🎯 How to Use These Recipes

### For API Testing:
1. Copy any of the JSON objects above
2. Go to your API documentation: `https://your-app.onrender.com/api-docs`
3. Find the **POST /api/recipes** endpoint
4. Click **"Try it out"**
5. Paste the JSON into the Request Body
6. Click **"Execute"**

### For Demonstration:
- **Different Categories**: Shows Appetizer, Main Course, Breakfast, Beverage
- **Various Difficulties**: Easy and Medium recipes
- **Search Testing**: Use different tags and categories to test filtering
- **Nutrition Data**: Each recipe includes calorie and macro information

### API Endpoints to Test:
- `GET /api/recipes` - See all recipes
- `GET /api/recipes?category=Appetizer` - Filter by category
- `GET /api/recipes?difficulty=Easy` - Filter by difficulty
- `POST /api/recipes` - Create new recipe
- `GET /api/recipes/{id}` - Get specific recipe by ID
- `PUT /api/recipes/{id}` - Update a recipe
- `DELETE /api/recipes/{id}` - Delete a recipe
